# Phase 5: Detail and Watch Experiences

## Goal

Create a premium, readable path from title discovery to playback.

## Detail pages

- Share one detail-page composition between movies and TV.
- Use a full-bleed hero with a glass metadata panel.
- Keep title, rating, year, type, synopsis, and primary actions in a clear
  hierarchy.
- Add robust invalid-ID and failed-request states.
- Keep cast and recommendations as adaptive rails.
- Provide trailer fallback and explicit mute state.

## Watch page

- Treat the player as the primary stage.
- Place controls in a responsive glass panel below or beside the player.
- Use a labelled server radio group or pressed-button group.
- Use native selects unless a custom listbox is implemented completely.
- Show player loading and failure states.
- Keep the third-party player notice visible and understandable.
- Make embed providers data-driven and ensure every visible server maps to a
  real destination.

## Acceptance criteria

- A user can recover from invalid media, failed metadata, and failed embeds.
- All watch controls work with keyboard and touch.
- Server and season/episode selections expose their current state.
- Detail and watch surfaces maintain contrast over any backdrop.
